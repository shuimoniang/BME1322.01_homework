## 1. 项目目标

本次作业要求在课程提供的统一血糖模拟器上，独立实现并比较两条无模型强化学习路线：

- **Part A（基于模型的学习）**：转移与奖励模型未知，先从交互经验中用计数法估计 P̂(s′|s,a) 与 R̂(s,a)，再在学到的模型上运行价值迭代求策略，思路是"先学模型、再规划"；
- **Part B（Q-Learning）**：同样不读真实模型，直接从给定经验中用表格 Q-Learning 更新 Q(s,a)，思路是"绕开模型、直接学价值"。

两条路线使用同一份交互数据（2000 条随机策略 episode），因此实验可以公平比较"学模型再规划"与"直接学 Q"两条思路的效果差异。

**环境**：模拟器有 9 个离散状态（B1 严重低血糖 至 B9 严重高血糖，B3 为目标区间），4 个动作（w 维持 / g 补糖 / i1 小剂量胰岛素 / i2 大剂量胰岛素，成本依次为 0 / -0.5 / -0.2 / -0.4），折扣因子 γ=0.9，每条轨迹最多 200 步。进入 B1 立即终止回合（类似"悬崖"问题的安全性约束），奖励为进入状态的基础奖励加动作成本。

## 3. 技术原理

**马尔可夫决策过程与 Bellman 最优方程（第 8 章）**。血糖调控可建模为折扣 MDP (S, A, P, R, γ)：智能体在状态 s 选动作 a，环境按转移概率 P(s′|s,a) 到达 s′ 并给出奖励。最优价值函数满足 Bellman 最优方程：

> V*(s) = max_a [ R(s,a) + γ · Σ_{s′} P(s′|s,a) · V*(s′) ]

价值迭代通过反复对该方程做同步扫描（每轮用旧 V 计算全部新 V）逼近 V*，γ<1 且奖励有界时保证收敛；策略提取取 π(s) = argmax_a Q(s,a)，其中 Q(s,a) = R(s,a) + γ Σ P̂ V。

**从经验中学习模型（第 9 章）**。Part A 不知真实 P/R，用计数法估计：P̂(s′|s,a) = N(s,a,s′)/N(s,a)（转移计数归一化），R̂(s,a) 为该 (s,a) 上所有奖励的样本均值。对从未访问的 (s,a)，取 P̂ 为均匀分布、R̂ 为 0：均匀分布是无信息先验，不预设某个转移更可能；两者结合保证 Bellman 备份良定义（概率和为 1、期望有限）。

**Q-Learning（第 9 章）**。Part B 是异策略时序差分控制，不需要模型：

> Q(s,a) ← (1−α)·Q(s,a) + α·[ r + γ·max_{a′} Q(s′,a′) ]

TD 目标取下一状态的贪心 max，因此即使行为策略不是贪心的也能收敛到 Q*。done=True 的转移（进入 B1 终止）目标中不含未来项。收敛三条件为：每个 (s,a) 被无限次充分访问、学习率满足 Robbins-Monro 条件（平方和发散、平方和收敛）、γ<1 且奖励有界。

**ε-greedy 探索与 Regret**。在线附加实验中，智能体以 ε 概率均匀随机探索、否则贪心。在 B1 终止的悬崖式环境里，一次探索动作可能导致整条轨迹提前终止，因此探索的代价（Regret）很高；衰减 ε 可以逐渐降低这一代价。

## 4. 实现方法与关键代码

### 4.1 Part A：模型估计与价值迭代（model_based.py）

模型估计的核心是三层计数结构 `counts[s][a][s']` 与逐 (s,a) 的奖励累加：

```python
for episode in episodes:
    for (state, action, reward, next_state, _done) in episode:
        bucket = self._counts[si][ai]
        bucket[next_state] = bucket.get(next_state, 0) + 1
        self._reward_sum[si][ai] += float(reward)
        self._reward_count[si][ai] += 1
...
if n_sa == 0:
    row_t.append({s: 1.0 / self._n_states for s in self.states})
    row_r.append(0.0)
else:
    dist = {
        ns: cnt / n_sa for ns, cnt in self._counts[si][ai].items()
    }
    row_t.append(dist)
    row_r.append(self._reward_sum[si][ai] / n_sa)
```

未访问 (s,a) 的兜底逻辑在估计阶段处理：`N(s,a)=0` 时转移字典取 `{s: 1/|S| for s in states}`、奖励取 0。价值迭代的同步扫描实现如下：

```python
for iterations in range(1, max_iterations + 1):
    delta = 0.0
    new_v = [0.0] * self._n_states
    for si, s in enumerate(self.states):
        best = None
        for ai in range(self._n_actions):
            q = self._q_from(si, ai, v)
            if best is None or q > best:
                best = q
        new_v[si] = best if best is not None else 0.0
        delta = max(delta, abs(new_v[si] - v[si]))
    v = new_v
    if delta < theta:
        break
```

本次数据上 82 轮收敛（max 差 < 1e-4）。策略提取用「严格大于才更新」的写法，保证平局时保留动作列表顺序（w,g,i1,i2）中的第一个，符合课程约定。

### 4.2 Part B：表格 Q-Learning（q_learning.py）

Q 表初始化为 0，`learn()` 按给定顺序逐条 episode、逐条转移调用 `update()`，不做任何动作采样（离线批量设定，与 Part A 公平对比）：

```python
def update(self, state, action, reward, next_state, done: bool) -> None:
    si = self._require_state(state)
    ai = self._require_action(action)
    nsi = self._require_state(next_state)

    r = float(reward)
    if done:
        target = r
    else:
        target = r + self.gamma * max(self.q[nsi])

    old = self.q[si][ai]
    self.q[si][ai] = (1.0 - self.alpha) * old + self.alpha * target
    self._visited[si][ai] = True
    self.update_count += 1
```

主实验 α=0.5，共更新 21825 次。`get_policy()` 返回每行 argmax，平局约定与 Part A 一致。ε-greedy 的 `select_action()` 与 `decay_epsilon()` 仅供附加在线实验使用。

### 4.3 实验入口与评估（main.py）

`evaluate_policy()` 把确定性策略放进模拟器：每条轨迹用独立种子 `GlucoseEnv(seed=90000+i)`，逐步累计无折扣回报、统计 B3 停留与 B1 终止。附加实验模块包括：

- 多块评估：5 个独立环境种子块各评 500 条，回报与 B3 占比报 t 区间（t 临界值手算，避免依赖 scipy），B1 终止率报池化 Wilson 区间；
- bootstrap 稳定性：有放回重采 episode 重学模型与策略，统计每个状态贪心动作的稳定率与 top-2 Q 差（翻转 margin）；
- 规划变体对比：同一 P̂/R̂ 上同步 VI / 异步 Gauss-Seidel / Q 直接迭代；
- 学习率消融：固定 α∈{0.1,…,1.0} 与 Robbins-Monro 调度（临时实现，不改提交文件）；
- 在线探索实验：三种 ε 设置 × 5 个随机种子 × 600 回合在线交互，滑动窗口 50 学习曲线。

### 4.4 预注册式选优流程（experiments/v3_study.py）

为避免"先看结果再挑参数"，学习率比较采用验证/测试分离：验证训练种子 11–15、验证环境种子 110000–110499 上选优；候选冻结到 `selection.json` 后，再用训练种子 21–25 重新从零训练，在独立环境种子段评估。在线训练的核心循环（学习率按每个 (s,a) 的累计更新次数调节）：

```python
while not done:
    a = agent.select_action(s)
    ns, r, done, _ = env.step(a)
    key = (s, a)
    counts[key] = counts.get(key, 0) + 1
    agent.alpha = learning_rate(cfg, counts[key])
    agent.update(s, a, r, ns, done)
    ret += r
    steps += 1
    b3 += int(ns == 'B3')
    s = ns
```

接受门槛与安全性判定：

```python
def admissible(candidate, baseline):
    return (candidate['b1_termination_rate'] <= baseline['b1_termination_rate']
            and candidate['b3_time_ratio'] >= baseline['b3_time_ratio'])

accepted = (delta['mean_return']['ci95'][0] > 0 and admissible(cm, bm))
```

即：回报差 95% 区间下界必须大于 0，且 B1 终止率不升、B3 占比不降；同时计算"安全性证据尚不足"标志（差值区间是否仍容许退步），如实随结果报告。运行纪律上，源码 SHA-256 写入 manifest，`--resume` 拒绝混合不同版本的实验数据，检查点原子写入。

价值结构合理：V̂ 在目标区 B3 达到峰值 4.77，向两侧单调递减。策略呈典型的"悬崖问题"形态：低血糖侧 B1/B2 立即补糖远离终止悬崖，目标区 B3 免费维持，高血糖侧按严重程度加大胰岛素剂量（i1→i2）。

讲义要求解释至少一个状态的策略选择，这里拿 B4（血糖略高）为什么选 i1 而不是 i2 来说。B4 离下方终止区 B1 只隔一个状态，经验模型中 i1 与 i2 的价值差约 0.597。i2 的平均降糖幅度更大，一步就可能把血糖推入低血糖区，即使进入 B3 有 +1 奖励，继续下穿到 B2/B1 的尾部风险期望损失更大；i1 大概率把血糖拉回目标区并留在安全带，动作成本也只有 i2 的一半。这是基于学到的经验模型的解释，不是读取真实转移表后的证明。

**B1 的终止语义**：进入 B1 的转移使回合结束，但 `reset()` 可能直接返回 B1，此时智能体仍须先选择动作，因此训练数据含 B1 出边、其动作有实际意义，V̂(B1)=1.76 非零不是未访问先验的产物。Part A 按讲义规定的 P̂/R̂ Bellman 式计算、不加终止掩码；Part B 对 done=True 的经验屏蔽未来项。两者对终止的处理不同，数值不应被当作同一终止模型下的最优解。

### 5.6 策略稳定性（bootstrap）

对统一数据预算做 30 次 episode 级 bootstrap（seed=1322）重学模型与策略：9 个状态的策略稳定率均为 100%；全表最脆弱的状态是 B4（top-2 价值间隔 0.60，全表最小），其 V̂ 的 95% 百分位区间为 [3.97, 4.84]。有限次重采样稳定不证明全局最优，但说明 B4 的 argmax 距离翻转边界有真实余量。

### 5.7 两路线对比分析

默认设置下两路线在 B2–B9 的一致率为 100%，主评估指标因此完全相同。相同数据预算下两条路线表现一致的原因：21,825 条转移对 9×4 的表格问题已经足够充分，模型估计误差（Part A）与 TD 采样噪声（Part B）都不足以翻转任何状态的 argmax。但第 5.9 节的种子消融显示，这一致只是主种子的特例：换一批数据后两路线即出现分歧，机制差异详见该节分析。

**规划变体**：同一 P̂/R̂ 上，异步 Gauss-Seidel 66 轮 vs 同步 82 轮（省 19% 扫描），Q 直接迭代 66 轮，三者策略完全一致、价值差 <5e-4。小表上同步扫描已足够，协议规定同步扫描是合理选择。

### 5.10 收敛三条件的讨论

- **充分访问**：有限轨迹只能保证所有 (s,a) 被访问过（本次 36/36，最少 18 次），不能证明无限次充分访问；种子消融中 Part B 的剧烈波动正是访问"足够但不无限"时的表现。
- **学习率**：固定 α=0.5 不满足平方可和的渐近条件，其 Q 值是近期样本的加权平均，保留尾部噪声；消融中 α=1.0 使策略在 B1/B4/B6/B8 四个状态翻转、回报跌至 75.56，是固定大步长风险的直接实证。带正下限的衰减调度同样不满足渐近条件；无正下限的调度在每对无限访问的假设下满足步长条件，但不保证有限回合内更优。
- **γ<1 且奖励有界**：任务条件已满足。γ 消融显示策略对该条件不敏感，但 γ 接近 1 时价值尺度和求解成本显著放大。

## 6. 迭代过程

这份报告里的几个结论被我们自己推翻过。按时间线记录如下，各版本的原始数据和报告都保存在 `experiments/` 里，可以对照。

第一版（10 月 26 日）完成了两路线的实现和课程必做实验，两策略一致，评估 88.01 / 63.4% / 0.8%，当时认为已比较完整。实现阶段做过协议审计和 17 项独立数值验证（用 mini-MDP 解析解和另一套独立写的 VI/QL 交叉核对），修掉了 3 个实现问题。现在回头看，这一版报告里至少有三处判断不成立：以为 B1 是终止状态、智能体在 B1 上选什么动作无所谓；拿规划变体对比和 Q 值 L2 误差当证据，说默认配置"已经最优"；还有那个 0.8% 的 B1 终止率，其实只是单块 500 条评估的点估计，没给任何区间。

第二版是同一天接着做的。我们先把讲义的红线逐句抄成一份核对清单（CONSTRAINTS.md），然后分三路做消融，专门检验第一版不成立的判断。先验消融试了 4 种未访问先验乘 8 档数据量，课程预算下结果完全一样。覆盖了不等于估准了，只是 argmax 碰巧没被翻转。学习率消融里 α=1.0 直接使 B6 等状态的策略翻转，回报从 88 跌至 75.56，第一次直观体现了固定大步长的风险。多块评估则显示 0.8% 落在合并 Wilson 区间 [0.25%, 0.79%] 的上缘：500 条样本对这种小概率事件没有足够的分辨率。

第三版（10 月 27 日）做了两件事。一是复核讲义后更正错误：reset() 可能直接返回 B1，这时智能体必须先选动作，所以 B1 的出边有实际意义，第一版"B1 从未行动"的解释是错的；旧版学习率调度带着 0.05 的正下限，并不满足 Robbins-Monro 条件，"已获得渐近收敛保证"和"已经最优"两句都撤了。后来才意识到，Q 值的 L2 误差是拿 Part A 的经验模型当参照算的，不是真实 Q*，误差小不等于回报高。二是把调参流程改成 4.4 节的两段式：先验证集选优、冻结，再换种子从零训练测试，失败的候选也全部留在结果里不删。

第四版（11 月 7 日）补了两个一直没检验的维度。换 10 个采集种子重跑全流程，发现 Part A 完全稳定，10 个种子的策略一模一样；Part B 却从 88.01 跌至 -40.05。原来第一版看到的"两路线完全一致"只是 seed=2026 的巧合。扫 γ 时发现策略对折扣因子完全不敏感，"γ 越大越怕 B1"的直觉也错了。

这几个被推翻的结论的问题出在同一个地方：把一次运行、一个种子的结果当成了普遍规律。想明白这一点之后，"结论要带区间、调参要先冻结、失败的实验也留档"就写进了我们的固定流程。

## 7. 总结

本次作业按课程协议实现了 Part A（计数法模型估计 + 同步价值迭代）和 Part B（原序单遍表格 Q-Learning），官方接口检查通过。讲义要求的实验（访问次数分布、策略/价值/Q 表、500 条评估、数据量消融、在线探索对比、两路线一致率与性能对比、收敛三条件讨论）全部完成，另外补了多块评估置信区间、bootstrap 稳定性、规划变体、学习率消融、验证选优独立测试、采集种子和 γ 消融七组附加实验。

最主要的发现有两个。第一，在统一数据预算下两条路线学到了完全相同的贪心策略（回报 88.01、B3 占比 63.4%、B1 终止率 0.8%），这个策略对数据量、采集种子和折扣因子都不敏感，说明 9 状态小表上 2000 条数据已经把策略结构学稳了。第二，策略相同不代表两条路线一样稳：换一批采集数据后模型路线纹丝不动，Q-Learning 的回报却大幅波动，两者的差别在价值传播方式上：全局规划把噪声平均掉了，逐条 TD 只能沿着数据里的路径传播。在线实验还显示悬崖环境会放大探索的代价，衰减 ε 明显好过固定 ε，而离线换学习率没有带来可证明的提升。

做下来最大的困难是分清三件事：讲义指定的算法、我们想优化的目标、评估用的口径。γ=0.9 的 Bellman 目标和 200 步无折扣回报不是一回事，学到的经验模型也不是真实环境。中途有几个结论被推翻，都是因为把这三样混在一起说了。

两条路线各有适用的场景。需要 what-if 分析或者想搞清楚"哪个状态缺数据"的时候，学模型更合适：模型是数据的压缩表示，价值迭代能把稀疏样本的信息全局传播，我们实验里它的稳定性也印证了这一点；代价是模型错了会被规划放大，价值迭代在错误的模型上求出的恰恰是错误模型的最优策略。环境难以建模（高维、部分可观测）时直接学 Q 更省事，但它对数据量和学习率更挑剔。如果继续做下去，我们会先给在线选优的结论补更多训练种子，再尝试用函数逼近（第 10 章预告）代替硬分箱，血糖本来就是连续量，共享相邻区间的样本能天然缓解稀疏问题。这些已经超出本次作业的范围，没有放进提交代码。
