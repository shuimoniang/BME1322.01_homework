# 手写数字识别：朴素贝叶斯与小型贝叶斯网络

## 1 任务与总体设计

### 1.1 任务定义

本次作业在标准 MNIST 数据集上完成 0–9 的手写数字分类，要求独立实现两个概率模型：一个朴素贝叶斯分类器和一个手工设计的小型贝叶斯网络。输入为展平后的 28×28 图像（784 维向量，像素值 0–255），输出为数字类别；训练集 60,000 张，测试集 10,000 张。两个模型的核心概率建模、参数估计与预测逻辑均以 NumPy 手写实现，不调用任何现成的朴素贝叶斯或贝叶斯网络库。

最终结果：朴素贝叶斯在完整测试集上的准确率为 97.81%，贝叶斯网络为 86.99%。

### 1.2 处理流程与代码结构

整体流程为：读取数据并展平为 (n, 784) 矩阵；朴素贝叶斯路径将像素二值化后编码为重叠的局部 patch 状态（第 2 节），贝叶斯网络路径提取 12 个语义离散特征（第 3 节）；训练完成后在完整测试集上评估，指标与图表写入 `figures/` 目录。

代码组织如下。`naive_bayes.py` 与 `bayes_net.py` 是按课程协议实现的模型文件，类名与方法签名与作业要求一致；`main.py` 是训练、评估与绘图入口，内置 IDX 读取器，直接解析课程数据目录中的四个 gzip 文件；`tests/` 存放单元测试；历史版本与逐轮实验记录保留在 `archive/` 与 `experiments_v2/`、`experiments_v3/`、`experiments_v4/` 中。

### 1.3 模型选择协议

所有超参数与结构选择均只在训练集内部完成。主验证划分由固定随机种子 1322 产生，为分层抽样，含 49,999 张训练图与 10,001 张验证图；对关键设计决策另用 8 个不同的训练内划分复核，避免结论依赖单次划分。测试集不参与任何选择，仅在最终模型确定后用于结果记录。第 4 节的全部测试集数字均来自最终代码在完整数据上的一次运行；筛选阶段的中间数字见实验目录中的记录，正文不再引用。

## 2 朴素贝叶斯分类器

### 2.1 概率模型

模型沿用作业给出的分解形式。将图像表示为一组离散变量后，类别后验为

$$
P(y \mid X) \propto P(y)\prod_{j=1}^{m} P(z_j \mid y),
\qquad
\hat{y} = \arg\max_y \Big[\log P(y) + \sum_{j=1}^{m} \log P(z_j \mid y)\Big],
$$

其中 $m$ 为变量个数。预测在对数域完成，避免长连乘下溢。

条件独立假设的具体含义是：给定类别后，各变量相互独立。图像中相邻像素高度相关，若直接以单个像素为变量，这一假设失真得最厉害。因此变量不取单个像素，而是把局部像素组编码为同一个变量，让最强的像素间依赖被吸收进变量内部；变量之间仍保持给定类别后的条件独立。这是对朴素贝叶斯的常见处理方式：改变特征的定义，而不改变模型的形式。变量的具体取法见下节。

### 2.2 特征定义：膨胀二值 patch

每张图像划分为 22×22 = 484 个重叠的 4×4 patch，步长为 1。patch 内的 16 个采样点在行、列方向上均每隔一个像素取一个，因此一个 patch 虽然只占用 16 个像素的状态，实际覆盖 7×7 的感受野。每个采样点按固定阈值二值化，pixel ≥ 72 记为墨迹（阈值由训练内划分上的比较选定），16 个二值位联合编码为一个取值范围为 2^16 = 65,536 的类别变量。

这样定义的出发点是状态预算与感受野的平衡。连续的 2×2 patch 只能看到边缘，分辨不出一段斜线、一个拐角和一块孤立墨迹的差别，而后者正是区分 4 与 9、3 与 8 这类数字的局部结构；把 16 个二值点铺得更开，同样的状态数覆盖了更大的局部模式。在此尺度上，有用信号主要是笔画的有无而非灰度深浅，所以每个采样点取二值而不是多档灰度。与备选方案的定量比较见 2.5 节。

### 2.3 参数估计与平滑

先验与条件概率由训练数据直接计数。对 65,536 状态的变量，逐状态的 Laplace 平滑（每个状态加一个伪计数）相当于向每个 patch 变量注入 65,536 个伪计数，正则化强度过大；实验中也观察到验证准确率随逐状态系数减小而持续上升，说明这一参数化在如此大的状态空间上并不稳定。

因此将平滑系数 α（即接口参数 alpha）定义为单个 patch 变量上的 Dirichlet 总质量，每个状态分得 α/65536 的伪计数：

$$
P(z_j = v \mid y = c) = \frac{N_{cjv} + \alpha/65536}{N_c + \alpha},
$$

其中 $N_{cjv}$ 是类别 $c$ 中变量 $z_j$ 取状态 $v$ 的样本数，$N_c$ 是类别 $c$ 的样本数。这一参数化下平滑强度与状态规模脱钩：在主验证划分上，α = 0.01、0.1、1、10 对应的验证准确率为 97.69%、97.65%、97.59%、97.48%，整体变化不超过 0.3 个百分点；协议默认的 α = 1.0 位于平坦区间内，故最终模型保留默认值。在 8 个不同的训练内划分上得到同样的结论，记录见 `experiments_v4/naive_bayes/results/`。

### 2.4 稀疏存储与预测

完整条件概率表的规模为 10 × 484 × 65,536，双精度存储约需 2.5 GB，而训练数据实际只覆盖其中约 4% 的（patch 位置，状态）组合。因此实现只保存观测到的组合的对数概率，未观测组合统一取平滑默认值 $\alpha/65536 / (N_c + \alpha)$。该默认值对所有类别相同，不会改变 argmax，因此压缩表示与完整 CPT 在预测意义上精确等价；每个 patch 变量的条件分布之和为 1，由 `check_probability_mass()` 验证。

预测时按批次（每批 1,024 张）累加对数先验与 484 个 patch 的对数条件概率；`predict_proba` 额外输出归一化后验。

## 3 小型贝叶斯网络分类器

### 3.1 特征提取与离散化

贝叶斯网络不直接建模像素，而是使用 12 个语义明确的离散特征，见表 2。固定网格特征取图像中央的 15×15 区域，划分为 3×3 个 5×5 的格子；其中中右、下右两个格子对书写位置和大小最敏感，改用图像自身墨迹包围盒的归一化坐标（包围盒按行、列各三等分），其余格子仍用固定坐标。特征的选择依据见 3.4 节。

表 2　贝叶斯网络的特征定义

| 特征 | 语义 | 离散化 | 状态数 |
|:---|:---|:---|---:|
| density_top_left / top_center / top_right / middle_left / middle_center / bottom_left | 固定网格对应格子的墨迹密度 | 状态 0 表示恰好无墨，正值按训练分位点分 4 档 | 5 |
| bbox_density_middle_right / bbox_density_bottom_right | 墨迹包围盒归一化坐标下，中行右格、下行右格的墨迹密度 | 同上 | 5 |
| euler_topology | 由 2×2 数字拓扑公式估计的连通分量数减去孔数，取值 −1, 0, 1, 2 | 直接映射 | 4 |
| vertical_runs | 每条占用列的平均竖直墨迹段数 | 状态 0 表示无墨，正值按训练分位点分 4 档 | 5 |
| aspect_ratio | 墨迹包围盒的宽高比 | 状态 0 表示退化情形，正值按训练分位点分 3 档 | 4 |
| vertical_dominance | 竖直方向梯度占绝对梯度总和的比例 | 按训练分位点分 4 档 | 4 |

所有连续特征的切分阈值在 `fit` 中由训练数据估计并保存，预测时固定复用。公开的 `extract_features(X)` 使用固定的规范切点而非训练分位点，保证单张图像的输出与同批其他样本无关，便于单独复用和检查。

### 3.2 网络结构

类别节点 Y 作为根指向全部 12 个特征，特征之间另有 11 条手工设计的有向边；每个特征至多两个父节点（Y 与至多一个特征），无隐藏变量，全部结构由人工设计。网络结构见图 1，每条边的语义见表 3。

![贝叶斯网络结构](figures/bayes_net_structure.png)

图 1　手工设计的贝叶斯网络结构（灰色边为 Y 指向特征的边，红色边为特征间的依赖边）

表 3　特征间边的语义

| 边 | 含义 |
|:---|:---|
| bottom_right → top_left | 对角方向墨迹占位的平衡 |
| top_left → top_center | 上部笔画的水平连续性 |
| top_center → top_right | 上部右侧收笔的连续性 |
| euler_topology → middle_left | 拓扑结构对中左区域的约束 |
| middle_left → middle_center | 中部水平笔画连续性 |
| euler_topology → bbox_middle_right | 拓扑结构对归一化右侧轮廓的约束 |
| bottom_right → bottom_left | 底部笔画的回折连续性 |
| bbox_middle_right → bbox_bottom_right | 右侧中下轮廓的连续性 |
| euler_topology → vertical_runs | 拓扑结构与竖直分段数的关系 |
| vertical_runs → aspect_ratio | 分段结构与宽高范围的关系 |
| vertical_runs → vertical_dominance | 分段结构与梯度方向性的关系 |

边的设计遵循两类语义。同一水平带内相邻网格的密度边刻画笔画的水平连续性：顶行自左向右成链，底行自右向左闭合，并由对角平衡边把右下与左上联系起来；拓扑与方向特征刻画整字层面的结构属性，因此由 euler 向中部轮廓与方向链发出约束边。

与朴素贝叶斯相比，两个模型的联合分布都分解为类别先验与各特征条件概率的乘积，差别仅在各条件概率所依赖的变量集合：朴素贝叶斯取 $P(z_j \mid y)$，条件只依赖类别 Y；贝叶斯网络允许 $P(F_i \mid y, \text{Parents}(F_i))$，条件中可以再包含个别特征。前者是后者在所有 $\text{Parents}(F_i)$ 为空时的特例，网络中多出的每条边都对应一个被显式承认的特征间依赖。

### 3.3 参数学习与平滑

CPT 由训练数据计数，并用类条件边缘分布作为回退先验进行平滑：

$$
P(F_i = v \mid y = c,\ F_p = u) = \frac{N(c, u, v) + \alpha\,\pi_c(v)}{N(c, u) + \alpha},
\qquad
\pi_c(v) = \frac{N(c, v) + \alpha}{N_c + K_i\,\alpha},
$$

其中 $F_p$ 是 $F_i$ 的特征父节点，$K_i$ 是 $F_i$ 的状态数，无特征父节点的 CPT 退化为普通的加性平滑。相比对每格均匀加 α，回退先验以该类别下 $F_i$ 的边缘分布为目标：某个父组合在训练中样本稀少时，条件分布向该类别下更常见的取值收缩，而不是向均匀分布收缩，同时每个 CPT 仍严格归一化。

预测按 $\log P(y) + \sum_i \log P(F_i \mid \text{Parents}(F_i))$ 累加。预测时所有特征均已观测，联合概率可直接逐项计算，不需要近似推理。

### 3.4 特征与结构的选择依据

特征层面经过两组消融。第一组确定网格与语义特征的组合：在中央区域网格密度的基础上，bottom_center 格与其他密度高度相关而删除；作业示例中的对称性、连通区域数、端点数等特征都做过尝试，它们在当前二值化与离散化方式下或者过于稀疏、或者与 Euler 数信息重复，替换网格特征后验证准确率反而下降，因此未保留。第二组确定包围盒特征的使用范围：把全部 8 个网格都改为包围盒坐标会损失绝对位置携带的类别信息，成绩下降；仅替换中右、下右两个轮廓格子时，8 个训练内划分平均提升 1.47 个百分点且全部划分一致提升，为最终采用。

结构层面比较了列链与行链两类手工拓扑：按列连接（top_left → middle_left → bottom_left）约 84.9%，按行连接并加入语义链后在主划分上达到 86.14%，说明同一水平带内的笔画连续性比纵向对齐更适合作为显式依赖。在此基础上加入两个包围盒特征，最终结构在主划分上为 86.40%（α = 1.0）。对结构微调使用跨划分配对 McNemar 检验并做 Bonferroni 校正，未通过校正的候选一律不采纳，避免在许多相近结构中挑中验证集上的偶然最高值。

表 4　贝叶斯网络方案比较（主验证划分）

| 方案 | 验证准确率 |
|:---|---:|
| 区域密度 + Euler + 竖直段（初始语义特征） | 约 83% |
| 列链 DAG | 约 84.9% |
| 行链 + 语义链 | 86.14% |
| 行链 + 语义链 + 两个包围盒特征（最终） | 86.40% |

## 4 实验评估

### 4.1 实验设置

最终模型以全部 60,000 张训练图训练，在完整 10,000 张测试图上评估。指标为 Accuracy、Macro Precision、Macro Recall、Macro F1 与 10×10 混淆矩阵，由 `main.py` 计算并写入 `figures/metrics.json`。复现命令为

```bash

```

该命令同时复现主划分上的 α 扫描（表 1 及本节数字由此而来）。

### 4.2 总体结果

表 5　测试集总体指标

| 模型 | Accuracy | Macro Precision | Macro Recall | Macro F1 |
|:---|---:|---:|---:|---:|
| Naive Bayes（膨胀二值 patch，α = 1.0） | **97.81%** | 97.80% | 97.81% | 97.80% |
| Bayesian Network（包围盒特征 + 手工 DAG，α = 1.0） | **86.99%** | 86.93% | 86.75% | 86.78% |

|:---|---:|---:|:---|
| Naive Bayes | 约 7.9 s | 约 2.3 s | 稀疏存储，仅保存观测到的（patch 位置，状态） |

两个模型约 10.8 个百分点的差距主要来自特征粒度。朴素贝叶斯的 484 个 patch 变量保留了笔画形状的细节，等价于一个状态空间极大的局部模式匹配器；贝叶斯网络的 12 个变量各自压缩了整字级别的属性，每变量至多 5 个状态，能区分的图像模式数量天然受限。反过来，贝叶斯网络的优势在于结构可解释——每条边都有明确的语义，参数量小，训练与预测都快一个量级。两者的取舍与课程对概率建模和 DAG 结构的考察目标一致，准确率差异本身不构成对贝叶斯网络的否定。

## 5 讨论与反思

本节按主题回顾开发过程中遇到的主要困难、当时考虑过的方案，以及最终的解决方式。除特别注明外，准确率均指主验证划分（49,999 / 10,001）上的结果。

### 5.1 单像素模型的准确率天花板与特征重定义

最初的朴素贝叶斯直接以 784 个像素为变量，7 档灰度加逐状态平滑只有 84.09%。观察错误样本可以发现症结：在逐像素统计中，一条连续斜线和几个互不相连的墨点几乎没有区别，而后者恰恰是区分 4 与 9、3 与 8 的局部结构。当时首先尝试的是经典二值化 Bernoulli 方案（阈值 16–160、α 四档扫描），结果只有 83.85%，比灰度基线更低——二值化丢掉了笔画深浅，单像素特征又对平移和形变过于敏感，两条路都没有带来改善。

随后把方向转向特征定义而不是模型形式：把 2×2 邻域的 4 个像素联合编码为一个离散变量，变量之间仍保持给定类别后的条件独立。这一步带来决定性的提升——二值编码 91.17%，4 档灰度 91.63%，5 档灰度 91.81%，比基线高约 7.7 个百分点。同一阶段还比较了三种容易被寄予期望的方案，均告失败：非重叠 patch（stride 2）只有 90.38%，缺少重叠带来的平移容忍；多视图拼接（patch 与像素视图、块聚合视图、不同档数 patch 两两组合）在 90.37%–91.69% 之间，全部不优于单一最优视图，原因是各视图高度相关，合并只引入冗余计数；TAN 半朴素结构需要在 729 个 patch 之间构建互信息生成树并为每类拟合 625×625 的 CPT，单次运行超过一小时未完成，且特征之间出现依赖边后已不再是朴素贝叶斯的连乘形式，计算与合规两方面都不成立。

灰度档数的扫描也留下一个教训：6 档（每 patch 625 → 1,296 状态）反而降到 91.40%，CPT 稀疏化的代价开始超过信息增益。这促成了"状态预算"的意识。后期重新审视特征几何时，判断 2×2 patch 的真正瓶颈是 7×7 的感受野仍然太小，而连续 4×4 patch（约 95%）只是把 16 个像素花在了过密的采样上。最终采用膨胀采样：16 个二值点间隔取像素，覆盖 7×7 感受野，验证准确率 97.59%。这一路走下来的结论是：条件独立假设摆在哪一层是朴素贝叶斯留给设计者的自由度，把强相关的像素并进同一个变量，模型形式不变而表达能力显著改变。

### 5.2 大状态空间下的平滑失效与 CPT 存储

膨胀 patch 把单个变量的状态数推到 65,536，两个此前不存在的问题随之出现。

第一个是平滑失效。逐状态的 Laplace 平滑（每状态加 α 个伪计数）在 α = 1.0 时相当于向每个 patch 变量注入 65,536 个伪计数，约为单个类别样本量的 13 倍，验证准确率跌至 95.4%；把 α 一路调小到 1e-10，准确率仍然单调上升。这说明问题不在 α 的取值而在参数化本身：逐状态参数化把平滑强度与状态数绑死，任何固定的 α 都不合适。早期小状态空间模型的经验也印证了这一点——625 状态时逐状态参数化尚可使用，最优 α 为 0.1（92.86%）；而当时首轮实验只扫了 0.5–2.0，错过小 α 区间，细扫才发现最优值，同一参数化在大状态空间上则彻底失效。最终的解决是把 α 重新定义为单个变量上的 Dirichlet 总质量，每状态伪计数为 α/65536（见 2.3 节）：主划分上 α ∈ [0.01, 10] 的极差缩小到 0.21 个百分点，8 个划分的均值为 97.58%（α = 1.0），且各划分均不低于 97.4%，协议默认值落在平坦区间中心。这次修正把"控制先验强度"这一目标与"每格加一"这一具体操作解耦开来。

第二个是存储。完整 CPT 为 10 × 484 × 65,536 双精度数组，约 2.5 GB，直接物化在不同机器上都有失败风险。检查训练数据发现（patch 位置，状态）组合的覆盖率只有约 4%，于是改为只保存观测组合的对数概率。该方案的正确性依赖一个事实：未观测组合的平滑默认值对所有类别相同，因而不影响 argmax，压缩表示与完整 CPT 在预测意义上精确等价。归一化由 `check_probability_mass()` 验证，预测结果与独立实现的稠密参照逐位比对一致。

### 5.3 特征预算约束下的取舍

贝叶斯网络一侧最大的困难不是公式而是预算：6–12 个特征、每个 2–5 个状态是硬约束，而最初有价值的候选超过了一打。最直接的一次教训来自超限方案：删除全局墨迹后凑成 13 特征（含 9 网格 + 4 语义）达到 84.97%，精修后 85.10%，均优于同期的 12 特征方案，但违反上限，只能放弃，退回 12 特征内重新组合得到 84.92%——为合规付出约 0.2 个百分点。

预算内的选择同样反复。特征族探索的结果是：纯 3×3 密度网格只有 74.0%，纯语义特征只有 54%–60%，两者组合 80.5%，说明网格密度是主体、语义特征只能补充；反过来用语义特征整槽替换网格密度，成绩全部掉到 74%–79%。随后又对 14 个方向性候选（梯度竖直占比、四角与侧壁开口墨迹、水平穿越次数、端点数、笔画宽度等）做过逐槽位替换，无一超过基线（最好的 84.42% 对 84.92%）——这些特征与网格密度信息高度冗余，而 5 档密度 CPT 的信息量更大。离散化上也有两个具体发现：把"恰好为零"单列为状态 0（其余正值按训练分位点分档）优于对全部数值直接分位切分；网格密度整体提到 6 档可以到 85.07%，但违反 2–5 状态约束，只能放弃。最终的组合是 8 个网格（删除与其他格子最冗余的 bottom_center）加 Euler 拓扑、竖直段数、宽高比、竖直梯度占比 4 个语义特征。这一阶段的总体认识是：预算紧张时，做减法（删冗余格子、删全局墨迹）比做加法有效，且每个特征应当语义清晰，否则组合再多也无法解释。

### 5.4 手工结构的选择与检验纪律

DAG 不允许自动学习，候选只能人工提出，而相近结构在单次划分上的差异很容易被误读为改进。列链定稿（自上而下连接网格）的验证准确率为 84.92%；随后在完全相同的 12 个特征上系统比较了 8 种人工拓扑：列链反转 84.47%、行链 85.87%、行链反转 84.22%、中心枢纽 84.35%、对角链 83.75%、完全无特征边（退化为朴素贝叶斯）83.37%。行链比列链高约 1 个百分点，与自左向右的笔画连续性一致；"无边"方案最差，也确认了显式依赖边的价值。在行链基础上闭合底行、并把语义特征接成以竖直段数为中心的链，达到 86.14%。

结构微调的候选数量随后快速膨胀，单次划分的最高值开始不可信。采取的纪律是三条：其一，同一配置在 seed 1322、7、2024 三个划分上复核，行链结构在三个划分上领先旧结构 0.95–1.22 个百分点，确认增益不是划分偶然；其二，对最终结构的三条新增边（euler_topology → middle_left、euler_topology → bbox_middle_right、bottom_right → top_left），在人工定义的结构族内独立复核——对该 DAG 做三次以内的边编辑共生成 502 个变体，该结构排第 5，族级置换检验 p ≈ 8×10⁻⁴，8 个划分全部优于旧结构（平均 +0.73 个百分点）；其三，配对 McNemar 检验加 Bonferroni 校正控制多重比较。基于这些复核结果，本文将这三条边的作用表述为"把中部轮廓条件于全局拓扑信号"，而不声称它们是该结构族内的唯一最优选择。

### 5.5 位置信息与形状信息的纠缠

固定网格的一个隐蔽缺陷在错误分析中暴露：同一个数字写得偏大、偏小、偏左或偏右时，墨迹会落进不同的格子，区域密度于是同时反映了形状和书写位置，6→0 一类错误与轮廓格子的位置敏感直接相关。第一个方案是把全部 8 个网格都改为包围盒归一化坐标，结果反而下降——绝对位置本身携带类别信息（数字在图像中的整体占位与偏移），全部归一化等于把它丢掉。最终只把对位置最敏感的中右、下右两个轮廓格子改为包围盒坐标，其余格子保留固定坐标；这一改动在 8 个训练内划分上平均提升 1.47 个百分点，且 8 个划分全部一致提升。经验是：归一化不是越多越好，一个特征最好只承载一种变化来源，两种信息纠缠时按敏感程度做局部替换。

### 5.6 实现错误的两次教训

过程中出现过两次典型的实现错误。第一次出现在贝叶斯网络的实验管线中：辅助脚本复现上一版定稿模型，只得 83.01%，与应有的 84.92% 对不上。逐格核对后发现实验代码的网格列序按行主序错位，实际删除的格子是 bottom_left 而非定稿模型中的 bottom_center；修正后与定稿模型的预测逐位一致，受影响的实验轮次全部重跑，实验记录只保留修正后的数字。第二次是更早的接线函数中一处索引偏移，导致当时评估的"列反转链"实际上是一个接错的 DAG（84.71%）；改用语义正确的接线后定稿。两次错误的共同点是：错位之后的结果依然"看起来合理"，只有当一个已知结果无法复现时，问题才会暴露。此后特征名称、网格坐标与父节点索引的对应关系由单元测试和固定的公开特征提取函数共同锁定，新的实验脚本以能否逐位复现定稿模型的预测作为第一道检查。

### 5.7 局限与可能的改进

朴素贝叶斯方面：patch 之间的长程依赖仍被忽略，97.81% 的高准确率不能解读为"像素近似独立得到了证实"，它仍然是一种计算上可行的近似；稀疏 CPT 的内存随状态空间增长，继续扩大感受野会遇到工程上限；对书写风格的连续形变（倾斜、非线性拉伸）只能靠局部模式的冗余补偿。可以尝试的方向是层级化的 patch 组织或预测后校准，但都需要先确认不越出朴素贝叶斯的形式范围。

贝叶斯网络方面：12 个粗粒度变量承载不了书写方向的细节，这是 86.99% 的主要原因；手工拓扑的改进幅度有限（5.4 节的复核也说明这一点），瓶颈更可能在特征质量而非连接方式。可以尝试在约束内引入少量方向性特征（如主梯度方向的分档）或对密度特征采用更细的状态划分，新增的每条边仍需保持可解释；所有改进以训练内多划分复核为前提，不使用自动结构学习。
