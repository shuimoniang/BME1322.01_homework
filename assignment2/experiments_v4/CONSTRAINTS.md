# Assignment 2 硬约束（rulebook for the v4 adversarial iteration）

来源：`Handwritten Digits Classification (Assignment - 2).pdf`，7 页。任何候选方案必须逐条满足；
违反任一条即为无效方案，无论验证准确率多高。Critic agent 的职责之一就是机械核对本文件。

## 数据集与协议

- 标准 MNIST：训练 60,000、测试 10,000，28×28 灰度，像素 0–255。
- 评测程序把图像展平为 `(n_samples, 784)` 传入模型。
- **所有模型选择只能使用训练集内部划分**；测试集只在定稿后评估一次。v4 统一协议：
  `stratified_split(y, validation_fraction=1/6, seed=1322)` → 49,999 训练 / 10,001 验证。
- 模型内部可自行二值化 / 归一化 / 离散化 / 特征提取，但必须在报告中说明。

## Naive Bayes（§1.1, §4.1）

- 模型形式必须是朴素贝叶斯：
  `P(y|X) ∝ P(y) · ∏_i P(x_i | y)`，预测 `argmax_y P(y) ∏_i P(x_i|y)`。
- 特征可以是原始像素或"简单离散化特征"；允许二值化（>0 或 >128）、归一化 0–1、灰度分档。
- 必须自行实现先验与条件概率估计；至少一种平滑；预测用**对数概率**累加。
- **禁止** `sklearn.naive_bayes.*` 或任何现成朴素贝叶斯实现。
- 特征之间在给定 y 后必须条件独立——这是"naive"的定义。因此：
  - ✅ 2×2 / 3×3 patch 内像素联合编码为一个状态、patch 之间条件独立：**合法**
    （特征被重新定义，NB 分解式不变）。
  - ✅ 多尺度 patch 视图拼接（每个视图的 patch 都各自条件独立于其余视图）：形式上仍是 NB，
    但属于强假设；若采纳必须在报告中说明并做验证集消融。
  - ❌ TAN / Chow-Liu 树：特征之间有依赖边，不再是 §1.1 的连乘式。**不采纳**
    （v2 已因该原因否决）。
  - ❌ 判别式方法、任何非生成式概率模型。

## Small Bayesian Network（§1.2, §4.2）

- 从原始图像提取 **6–12 个离散特征**；每个特征语义明确，离散为 **2–5 个取值**。
- 结构：节点 = 类别 Y + 6–12 特征节点；**Y 是根节点**；**至少 2 条特征之间的有向边**；
  **每个特征节点的父节点数 ≤ 2**（含 Y 在内）；**无隐藏变量**；**禁止自动结构学习算法**。
- 全部 CPT 用训练数据估计，**每个 CPT 都要平滑**。
- 预测用对数联合概率：`log P(y) + Σ_i log P(F_i | Parents(F_i))`；所有特征已观测，无需近似推理。
- **禁止** `pgmpy`、`bnlearn` 或其他现成贝叶斯网络库。
- 报告必须画结构图并逐条解释每条边的语义。
- PDF §1.2 明确列举可用特征类型（这些都在界内，且当前模型尚未用满）：
  上/中/下墨迹密度、左/中/右墨迹密度、**宽高比**、**水平对称性**、**垂直对称性**、
  **笔画连通区域数量**。

## 评分导向（§5）

"评测重点不是追求最高精度，而是否理解条件独立假设、DAG 结构、CPT 估计与平滑的差异。"
因此：候选方案的**每一步都必须是可解释的概率建模改进**，而不是对验证集的调参堆砌；
报告中要能讲清"为什么这样建模"。若某方案只涨 0.1pt 却让报告难以解释，应优先可解释性。
PDF 也允许"目前的方法已经很好，不必强求更好"——如果迭代无真实增益，保留现行方案是正确结论。
