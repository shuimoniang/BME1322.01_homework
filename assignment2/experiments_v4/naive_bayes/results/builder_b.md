# Builder B — Naive Bayes 参数估计 / 平滑 / 先验（experiments_v4）

方法族：**CPT 与先验的估计方式**（不改特征几何、不改独立性结构）。
协议：`v4_common.load_split()`，49,999 训练 / 10,001 验证，seed 1322；只读训练集 60,000，
**测试集从未打开**。所有实验脚本：`candidates/builder_b_experiments.py`（分节，结果写入
`candidates/builder_b_results.json`）。所有随机性固定 seed 1322。

先行复核：现行 `naive_bayes.NaiveBayesClassifier(alpha=0.05)` 在 seed 1322 验证集上
**0.9298**，与 `BASELINE.md` 一致；快速向量化复现 harness 逐位给出同样的 0.9298/0.9273/
0.9182/0.9118。基线可复现，实验继续。

## 3. 机制：为什么必须压小 α

**观测 1 — CPT 极度稀疏**（`zero_stats` 节）：10×729×625 = 4,556,250 个单元中
**85.93% 计数为 0**；每状态平均计数仅 8.0。三类中数字“1”最稀疏（92.98% 零），
“8/2”最密（83.0%）。

**观测 2 — 但真正“命中空状态”的样本很少**：验证样本在其真实类别下平均只有
**4.09 个 patch 处于零计数状态**（729 个 patch 中），**75.2%** 的样本至少命中 1 个；
逐类未见过状态占比仅 9.1%–12.6%。也就是说，**625−1 个（对多数 patch 几乎）从不出现的状态
拿走了 α 注入的绝大部分质量**，而真正需要“兜底”的少数未见状态只应分到极小质量。

**观测 3 — 显式解耦实验确认了机制**：把“已见状态的平滑 a_seen”和“未见状态的兜底 a_zero”
分开后，验证准确率**只随 a_zero 变化**，与 a_seen 无关：

| a_zero | 0.9298→ | |
|:--:|---:|---|
| 1e-4 | 0.9395 | a_seen ∈ {1e-4, 3e-4, 1e-3} 三行完全相同 |
| 1e-3 | 0.9373 | |
| 1e-2 | 0.9337 | |
| 0.05 | 0.9297 | |
| 0.1 | 0.9274 | |
| 0.3 | 0.9230 | |
| 1.0 | 0.9132 | |

**解释**：均匀 Lidstone 先验把“同类已见状态”的密度按 α 压低、把“同类从未见的 621+ 个状态”
抬高。由于各 patch 的零状态分布极不均匀（中心 patch 状态数约 101.9，边界 patch 仅约 4.1），
α 越大越偏袒 CPT 更密的类别（笔画覆盖 patch 多的数字，如 8），对“1”这类稀疏类别不公平。
把 α 压到 1e-4 基本消除该偏差，同时因 α>0 仍保证全支撑、无 log(0)。这也解释了为何
现行 α=0.05 偏强——它是需要被纠正的估计偏差，而非欠拟合的正则化。

## 4. 各想法：假设、机制、结果与否决理由

### 想法 1（采纳）：小 α 渐近 + 平台取点
见 §2、§3。这是本族唯一真实增益，且**完全是纯平滑**（形式与现行逐字相同，只是常数不同），
不涉及任何建模延伸，最保守、最易解释。可直接替换 `naive_bayes.py` 的 α 默认值。

### 想法 2（否决）：MML / 经验贝叶斯（Dirichlet-multinomial 边缘似然）选 κ
用纯 NumPy Lanczos `lgamma`（自检误差 7.3e-12，未用 scipy）精确计算每个 CPT 的
Dirichlet-multinomial 边缘似然，在训练计数上网格搜边缘似然最大的总强度 κ。
**结果：MML 峰值在 κ=10（等价 Lidstone α≈0.016），验证仅 0.9327**；逐类 MML 0.9321、
逐 CPT MML 0.9300。改用 parent=pixel-product 时 MML 选到 κ=100（α≈0.16）→ 0.9252。
**否决理由**：MML 最优化的是训练数据的边际似然（等价于留一式交叉熵/对数损失），
它不是 0-1 分类准确率；在本问题上它系统性**过平滑**，选出的 α 比准确率最优大约
2 个数量级。这是一个诚实、可解释的负结果：**边缘似然准则与 MAP 分类准确率在这里明显失配**。
（该准则只用训练计数，未碰验证/测试。）

### 想法 3（否决）：Witten-Bell 自适应平滑
经典自适应规则 α_j = T_j/(N_j+T_j)·scale，T_j 为 CPT j 的观测状态数、N_j 为总计数，
边界稀疏 patch 得到更大 α、中心密集 patch 更小。逐 CPT 最优 scale=0.05 → **0.9362**；
逐类最优 scale=0.05 → **0.9370**；scale=0 时因无兜底崩塌到 0.3196。
**否决理由**：数据自适应方向是对的（都优于 α=0.05），但都不如“统一 α=1e-4”。原因是小 α
本身已把“已见状态平滑”压到近乎无效，此时唯一要紧的是统一的最小兜底项；按占用率分配 α
反而在密集 CPT 上制造了不必要的不均匀。**否决：没有超过简单小 α。**

### 想法 4（否决）：层级 / 回退平滑（Dirichlet 先验均值取更粗父分布）
把每个 patch-state 条件概率向四种父分布收缩，κ 网格扫描：
- **uniform 父**：最优 κ=0.05（≈α=8e-5）→ 0.9398（这其实是想法 1 的同一解）；
- **global_freq 父**（类无关的全局状态频率）：最优 κ=0.03 → 0.9388；
- **pooled3x3_freq 父**（按 3×3 位置池化）：最优 κ=0.01 → 0.9385；
- **pixel_product 父**（patch 内 4 像素独立的边缘乘积，即退化到逐像素 NB）：最优 κ=1e-3 → 0.9351。
**否决理由**：非均匀父分布（尤其 pixel_product）把 CPT 拉向一个更“平滑但更错”的分布，
反而破坏了 2×2 联合模式的价值；只在极小 κ 下才接近小 α 解，但始终不如 pure small-α。
小 κ + 非均匀父 的组合（κ∈{1e-3..0.05}）分别只有 0.9387/0.9385/0.9382/0.9384，**无一超过 0.9395**。

### 想法 5（否决）：温度 / 加权 NB `P(y)·∏P(z_j|y)^{w}`，w<1
动机：729 个高度重叠 patch 远非条件独立，对数似然被过度累加，用 w<1 降温。
短期**在报告中明确标注为建模延伸**，并按要求同时保留纯平滑候选（想法 1）。
**结果：曲线完全平**——α=0.05 时 w 从 1.0 降到 0.3，准确率仅 0.9298→0.9294；
α=1e-4 时 w∈{1.0..0.3} 恒为 0.9395。**否决理由**：温度是全局缩放，对所有类别同等作用，
而这里的误差来源是**类间不均匀的零状态偏置**，缩放不改变 argmax 的相对次序结构到足以纠偏；
既然它在额外 seed 上也不产生增益，且属于建模延伸（可解释性更差），不予采纳。

### 想法 6（否决）：类边缘先验变体
经验类先验（α=0.05 / 1.0）vs 完全均匀先验，在特征 α=0.05 与 0.01 下**结果逐位相同**
（0.9298 / 0.9337）。MNIST 各类近乎均衡（49,999 训练中每类约 5,000），类先验对该模型
的决策几乎不起作用。**否决：无效**。（也说明增益全部来自条件 CPT，不是先验。）

### 想法 7（佐证）：训练内部嵌套选 α（不偷看验证集）
为排除“α=1e-4 是验证集调出来的”，在 49,999 训练行内部再做 `stratified_split`
（子训练/子验证），**仅用子验证选 α**，再在全训练集上重估、只在主验证集上报告。
子划分比例 1/6、1/4、1/2 三种下，内层曲线都单调指向最小格点，**一致选中 α=1e-6，
主验证 0.9387**（≈ 我们用完整验证选出的 0.9395，差距来自内层数据更少）。
**结论**：小 α 不是验证集过拟合，训练数据自身的泛化曲线就指向同一 regime。

### 附加：位置自适应 α（边界 vs 内部）
边界 patch 平均仅 4.1 个不同状态、内部 101.9 个，本应差异最大。把内部 α 设为边界的
0.5/0.25/0.1 倍，结果 0.9395–0.9398，与统一小 α **无差异**。**否决：机制上可解释
（兜底项才是决定因素），但无增量。**

## 5. 最终裁决

**ADOPT — 推荐 α = 1e-4。**

- 主验证（seed 1322）：**0.9395**（现行 0.9298，**+0.97pt**）
- 交叉 seed：seed 7 **0.9368**（现行 0.9276）、seed 2024 **0.9406**（现行 0.9318），
  三个 seed 全部 +0.88~0.97pt
- McNemar（候选 vs 现行）：主划分 **b=164, c=67, p=1.4e-10**；
  seed 7 **p=3.9e-10**；seed 2024 **p=1.1e-9** —— 三个划分全部 p≪0.05
- paired bootstrap 95% CI（Δacc）：**[+0.0067, +0.0128]**，不含 0
- macro F1：0.9393；主要混淆对 (3→8: 38)、(7→9: 37)、(5→3: 29)、(8→3: 27)、(3→2: 25)，
  与现行同构，未见新引入的系统性错误

诚实性说明：
1. 这是**唯一**站得住的本族结论，且它是纯 Lidstone 平滑常数的改动——最保守、最可解释，
   完全满足 CONSTRAINTS.md 的“genuinely in-bounds、可解释”要求。**无任何特征几何或
   独立性结构改动，无建模延伸。**
2. α=3e-5 经验最高（主验证 0.9402、三点均值 0.93947），但与 α=1e-4 差异**不显著**
   （p=0.14），且更靠近 α→1e-6 的崩塌边界；故推荐平台内更稳健的 **1e-4**。
   若主会话偏好纯经验最大值，用 3e-5 亦可，二者实质等价。
3. 本族其余 5 类想法（MML 自适应、Witten-Bell、层级回退、温度化、类先验）**均无真实增益**，
   如实报告为负结果；其中 MML“边缘似然与 0-1 准确率失配”本身是有报告价值的科学发现。
4. 若主会话要维持“纯平滑、零建模延伸”的最强形式，采纳 α=1e-4 与本研究一致；
   温度化方案本族**不建议**采纳。
