# Naive Bayes v2 最终测试结果

模型：2×2 重叠 patch 灰度模式朴素贝叶斯（729 个 patch 特征，每 patch 4 像素各 5 档灰度联合编码为 625 状态，alpha=0.5，纯 NumPy）。

选择过程仅使用训练集内部分层划分（seed 1322，49,999/10,001），验证准确率 91.81%。以下为定稿后在完整测试集（10,000 张，唯一一次使用）上的结果：

| 指标 | 数值 |
|:---|---:|
| Accuracy | **92.86%** |
| Macro F1 | 92.80% |
| fit / predict 耗时 | 2.4 s / 0.7 s（NumPy 向量化） |

## 与基线对比

| 版本 | 验证 Acc (seed 1322) | 测试 Acc | 测试 Macro F1 |
|:---|---:|---:|---:|
| v1 基线（784 像素 7 档灰度，alpha=0.1） | 84.09% | 84.97% | 84.79% |
| v2 最终（729 个 2×2 patch 模式，alpha=0.5） | **91.81%** | **92.86%** | **92.80%** |

核心改进：把"特征在给定类别后条件独立"的假设从单像素层面提升到 2×2 patch 层面——patch 内的像素相关性被联合编码吸收，patch 之间保持条件独立。模型仍是严格的朴素贝叶斯框架 P(y)·∏P(z_j|y)，全部参数估计与预测自实现。

> 监督备注（supervisor takeover）：第 5 轮 TAN 实验因 NB agent 中断未完成，未采纳；最终采纳第 4 轮 patch-L5 模型（验证 91.81%）。以上测试结果由监督者用定稿后的 naive_bayes.py（与 naive_bayes_candidate.py 一致）在全部 60,000 训练图上重训、10,000 测试图上评估一次得到，单元测试 9/9 通过。
