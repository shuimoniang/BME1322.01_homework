## 06. 加入二次交互特征后，训练更好但验证明显更差

对应作业条款：4.3（1）；4.5（4）。现象类别：本数据上的模型容量。

研究意义：二次展开提高训练成绩却降低验证成绩，支持小样本容量收益不足的解释。

直觉预期：更丰富的交互关系可能提高模型表达能力和验证成绩。

- 数字对照：岭回归家族，训练R²：原始13维 **0.571514** → 二次104维 **0.681918**。
- 数字对照：岭回归家族，验证R²：原始13维 **0.524346** → 二次104维 **0.378840**。

可检验的原因假设：104维系数在小样本中可能吸收偶然关系，正则化未完全抵消估计方差增加。

已完成的验证方式：原始及二次模型分别扫描alpha，所有变换折内拟合，同时比较训练与验证成绩；二次模型最优alpha=100。

验证结果与边界：训练改善与验证下降并存，支持当前数据下容量收益不足的解释。

进一步验证：可做训练集规模学习曲线，检验增加样本后容量劣势是否减轻；本次未作该额外实验。

## 07. 只改变随机划分，就能得到正负两种R²结论

对应作业条款：4.5（3）。现象类别：数据划分敏感性。

研究意义：只改变划分就能改变R²的符号，单次划分无法支持稳定结论。

直觉预期：固定算法与参数的评价结果可能应比较稳定。

- 数字对照：深度3回归树，单次80/20测试R²：十次最小值 **-0.200833** → 十次最大值 **0.315068**。
- 数字对照：深度3回归树，R²：单次最小值 **-0.200833** → 固定五折平均 **0.292150**。

可检验的原因假设：约61人的测试集对重症比例和个别大误差敏感；训练样本变化也会改变树结构。

已完成的验证方式：固定树参数及树种子，只将划分种子设为0–9，报告全部十次结果；标准差=0.131900。

验证结果与边界：挑最好一次会夸大表现；一次负R²也不能证明模型在所有划分上无效。

进一步验证：若需不确定区间，应采用预先指定的重复评估设计，不能只增加有利种子。

## 08. 深树训练完全拟合，验证几乎没有解释力

对应作业条款：4.3（1）。现象类别：本数据上的树容量。

研究意义：叶内样本数量为深树训练拟合与泛化的矛盾提供机制证据。

直觉预期：更多分裂能够利用更多规律，可能提高预测效果。

- 数字对照：回归树，训练R²：深度3 **0.568319** → 无限深 **1.000000**。
- 数字对照：回归树，验证R²：深度3 **0.292150** → 无限深 **0.003372**。
- 数字对照：回归树，平均叶节点数：深度3 **8.000000** → 无限深 **82.800000**。
- 数字对照：回归树，单例叶比例均值：深度3 **0.025000** → 无限深 **0.479665**。

可检验的原因假设：小叶节点均值对单个患者标签过于敏感，单例叶直接记忆训练标签，估计方差增大。

已完成的验证方式：完成深度1–12及None扫描，记录训练与验证成绩、叶内样本数和单例叶比例。

验证结果与边界：训练R²达到1时验证R²仅约0.003，伴随叶节点细碎化，支持小样本叶均值不稳定的解释。

进一步验证：可在训练内重采样比较叶结构及预测方差，进一步隔离样本扰动效应。

## 09. RBF训练排序完美，验证分类却接近多数类

对应作业条款：4.2（2）；4.6（1）。现象类别：本数据上的核局部化。

研究意义：固定C下增大gamma造成训练与验证分离，直接回应讲义的过拟合论断。

直觉预期：更精细的局部拟合可能同时提高训练和验证表现。

- 数字对照：RBF SVM，C=1，训练AUC：gamma=0.01 **0.922924** → gamma=10 **1.000000**。
- 数字对照：RBF SVM，C=1，验证AUC：gamma=0.01 **0.908592** → gamma=10 **0.711969**。
- 数字对照：gamma=10与多数类，验证accuracy：RBF SVM **0.541257** → 多数类参考线 **0.541257**。

可检验的原因假设：核相似度随gamma增大快速衰减，模型记住局部训练响应，未见样本的分数可能集中在默认判别阈值一侧。

已完成的验证方式：固定C、折和预处理，只改变gamma，同时检查训练AUC、验证AUC、accuracy及支持向量数。

验证结果与边界：训练与验证差距扩大；AUC仍高于0.5而accuracy接近多数类，说明排序和默认决策不能混为一谈。

进一步验证：可进一步检查外层测试分数分布和训练内阈值选择，不将当前证据称为高维孤岛形状的直接观察。

## 10. 按AUC选出的最优配置，召回率反而下降

对应作业条款：4.2（1）；4.6（1）。现象类别：排序与筛查决策的权衡。

研究意义：按AUC选参并不保证默认阈值下的召回率改善。

直觉预期：调参得到最优模型后，各项指标可能一起改善。

- 数字对照：线性SVM，验证AUC：C=1 **0.910463** → C=0.01 **0.911160**。
- 数字对照：线性SVM，验证recall：C=1 **0.798413** → C=0.01 **0.784127**。

可检验的原因假设：选参目标为排序AUC，未优化默认阈值下的召回率；分数排序和类别决策是不同目标。

已完成的验证方式：对相同测试折同时计算五项分类指标并核对混淆矩阵。

验证结果与边界：AUC和accuracy提升不代表漏诊减少，最优必须限定评价指标。

进一步验证：若优先召回，应在训练数据内设定召回约束和阈值，再进行独立评估。

## 11. 复杂核没有取得更好的分类排序

对应作业条款：4.2（1）；4.6（1）（2）。现象类别：本数据上的核选择。

研究意义：简单核在本次评估中略优，但微小差距不足以宣称普遍优势。

直觉预期：表达能力更强的RBF核可能超过线性核。

- 数字对照：SVM，五折AUC：线性核最优 **0.911160** → RBF核最优 **0.910040**。
- 数字对照：SVM，外层AUC：线性核 **0.904554** → RBF核 **0.897433**。

可检验的原因假设：在303例小样本中，全局平滑关系可能已足够；RBF增加的局部拟合方差抵消了表达能力收益。

已完成的验证方式：分别完成双核网格扫描，并用同一固定折进行嵌套选参；比较训练与验证差距。

验证结果与边界：两种评估口径均倾向线性核，但扫描后差距较小，不能解释为显著或普遍优势。

进一步验证：扩大RBF边界网格，并在保持外层隔离的条件下检验；需要独立数据才能判断可推广性。

## 12. 标准化的收益和最优C漂移并不一致

对应作业条款：4.2（4）；4.5（2）。现象类别：尺度与参数的共同作用。

研究意义：尺度收益与最优C漂移不一致，不能统一解释两个核的反应。

直觉预期：两个SVM可能对尺度同样敏感，或者最优C都应同方向漂移。

- 数字对照：线性SVM最优，验证AUC：标准化 **0.911160** → 不标准化 **0.908709**。
- 数字对照：RBF SVM最优，验证AUC：标准化 **0.910040** → 不标准化 **0.874310**。
- 数字对照：线性SVM，最优C：标准化 **0.010000** → 不标准化 **1.000000**。
- 数字对照：RBF SVM，最优C：标准化 **100.000000** → 不标准化 **100.000000**。

可检验的原因假设：线性权重惩罚与RBF距离受尺度影响的方式不同；RBF的scale还随总体方差变化，超参数可部分补偿尺度。

已完成的验证方式：在标准化和不标准化两种折内管线中各自扫描，保留完整候选和最优参数。

验证结果与边界：线性核最优C漂移而RBF最优C未变，但RBF的AUC下降更大；重新选参比较不等于只改变尺度的单因素机制证明。

进一步验证：可固定C与数值gamma逐项配对比较，分离尺度变化和重新选参的影响。

## 13. 相同alpha下Lasso的稀疏程度随训练折变化

对应作业条款：4.3（3）。现象类别：稀疏解的折间稳定性。

研究意义：变量选择随折变化是实测现象，但相关性是否为原因还需受控验证。

直觉预期：选定一个正则化强度后，筛选出的变量可能应保持一致。

- 数字对照：Lasso，alpha=0.01，零系数数量：外层训练折1 **0.000000** → 外层训练折4 **2.000000**。

可检验的原因假设：弱贡献特征的系数接近阈值，训练样本及相关输入的变化可能改变变量是否被压到零。

已完成的验证方式：逐特征检查五折系数、非零频次及标准差，并结合相关结构表。

验证结果与边界：五折零系数数量为[0, 1, 0, 2, 0]，证明存在折间选择差异，但不能仅据此断言由相关性导致或选择近乎随机。

进一步验证：需要训练内bootstrap或受控相关特征实验检验选择频率及原因；本次尚未执行。

## 14. Lasso全部系数为零，R²为负，且与均值参考一致

对应作业条款：4.3（3）（4）。现象类别：模型退化与均值参考。

研究意义：全零系数和负R²反映强收缩及训练测试均值差异，不应误判为程序错误。

直觉预期：严重收缩后可能仍保留少数重要变量，常数参考的R²应为0。

- 数字对照：Lasso，平均零系数数：alpha=0.01 **0.600000** → alpha=10 **13.000000**。
- 数字对照：Lasso，验证R²：alpha=0.01 **0.525461** → alpha=10 **-0.011653**。
- 数字对照：常数预测，验证R²：全零Lasso **-0.011653** → 训练均值参考 **-0.011653**。

可检验的原因假设：强惩罚使系数全零但截距仍等于训练均值；测试均值与训练均值不同，所以常数模型测试R²可为负。

已完成的验证方式：检查逐折零系数计数，并比较全零Lasso与DummyRegressor的折外预测。

验证结果与边界：负R²属于正常退化，不是程序报错；R²=0的概念参照不能代替真正的折外均值基线。

进一步验证：已完成预测相等性检查；不需要为了非负R²去改动测试预测。

## 15. 增大C提高训练AUC，却降低验证AUC

对应作业条款：4.2（3）。现象类别：本数据上的惩罚参数。

研究意义：固定gamma改变C，可以区分训练拟合收益与验证损失。

直觉预期：更重视训练违例的惩罚可能提高整体准确性。

- 数字对照：RBF SVM，gamma=0.01，训练AUC：C=1 **0.922924** → C=100 **0.974781**。
- 数字对照：RBF SVM，gamma=0.01，验证AUC：C=1 **0.908592** → C=100 **0.869393**。

可检验的原因假设：大C相对减弱正则化，使模型更愿意为训练点形成复杂分界，可能拟合噪声。

已完成的验证方式：保持gamma=0.01和五折划分不变，对照C扫描的训练及验证指标。

验证结果与边界：在该gamma下观察到拟合与泛化反向变化；不能推广为任意gamma下大C都会更差。

进一步验证：对不同gamma重复同样比较，并在外层测试中验证参数选择的稳定性。

## 16. 独立选参不一定让成绩下降，岭回归成绩完全相同

对应作业条款：4.3（3）；评估协议。现象类别：参数稳定性与选参协议。

研究意义：外层成绩不必然下降，参数选择稳定时可与固定五折成绩完全相同。

直觉预期：经过内层重新选择参数后，外层成绩可能必然低于扫描最优。

- 数字对照：岭回归，R²：课程扫描最优 **0.524346** → 独立外层 **0.524346**。
- 数字对照：预剪枝回归树，R²：课程扫描最优 **0.292150** → 独立外层 **0.209500**。

可检验的原因假设：若每个外层的内层选择都得到相同参数，外层重新拟合与固定五折中对应模型可完全一致；下降不是嵌套评估的必然数学性质。

已完成的验证方式：检查五个外层选择的参数和逐样本预测，岭回归五次均选择alpha=10。

验证结果与边界：岭回归参数稳定，而树的选择更受训练样本变化影响；相同数字本身不能作为泄漏证据。

进一步验证：外层隔离仍由协议测试检查；需要外部数据才能评估当前数据来源以外的表现。

## 17. 岭回归适度正则化收益很小，惩罚过强反而接近失效

对应作业条款：4.3（3）。现象类别：本数据上的正则化收益。

研究意义：适度收缩收益有限，而过强惩罚又会损失预测信号。

直觉预期：加入或增大正则化可能显著改善线性模型。

- 数字对照：线性回归家族，验证R²：普通最小二乘 **0.522537** → 最优岭alpha=10 **0.524346**。
- 数字对照：岭回归，验证R²：alpha=10 **0.524346** → alpha=10000 **0.058621**。

可检验的原因假设：13个输入上的普通线性解已较稳定，适度收缩仅带来小收益；过强惩罚压制了有用信号，形成欠拟合。

已完成的验证方式：跨多个数量级扫描alpha，并对照OLS、训练成绩和标准化系数。

验证结果与边界：适度正则化改善有限；不能把正则化越强与泛化越好画等号。

进一步验证：可用训练内重采样比较系数方差，区分方差降低与偏差增加的贡献。

## 18. 目标只取0–4，普通线性回归却预测负等级

对应作业条款：4.3；4.6（3）。现象类别：输出约束与等级目标。

研究意义：标签范围不自动约束无约束回归的预测范围，提示模型与任务尺度的差异。

直觉预期：训练目标有界且非负，预测可能也应在相同范围。

- 数字对照：普通最小二乘，数值范围：真实目标最小值 **0.000000** → 折外预测最小值 **-0.616897**。
- 数字对照：普通最小二乘，负值预测人数：按标签范围预期 **0.000000** → 303例实际预测 **49.000000**。

可检验的原因假设：无约束线性函数输出不受目标取值范围限制，平方损失也不会自动施加上下界。

已完成的验证方式：遍历全部折外预测，统计最小值、最大值和越界人数；保留原值计算课程指标。

验证结果与边界：负预测是模型约束与等级任务不一致的表现，不是读错标签；事后截断会改变评价协议。

进一步验证：若比较截断版本，须作为预先声明的单独对照，不能静默修改正式结果。

## 19. 某折验证R²高于训练R²，但验证MSE反而更大

对应作业条款：4.4；4.6（2）。现象类别：指标归一化口径。

研究意义：跨训练和验证集合的R²不能直接替代绝对误差比较。

直觉预期：验证R²较高可能意味着新样本的实际预测误差更小。

- 数字对照：OLS，第1折，R²：训练 **0.558224** → 验证 **0.578279**。
- 数字对照：OLS，第1折，MSE：训练 **0.638034** → 验证 **0.732827**。
- 数字对照：OLS，第1折，标签方差（由MSE和R²还原）：训练 **1.444249** → 验证 **1.737705**。

可检验的原因假设：R²按各自被评估集合的标签方差归一化，训练集与测试集的分母不同，不能直接以R²大小判断绝对误差。

已完成的验证方式：读取同一折训练与验证MSE、R²，按R²=1−MSE/Var(y)核对分母。

验证结果与边界：测试标签方差较大，足以使更大的MSE得到更高R²；不能据此声称模型在新患者上优于训练患者。

进一步验证：跨集合比较时同时给出MAE、MSE和标签分布，避免只看R²。
