# 三题简答

## 1. 线性核与RBF核

线性核。两种核各自调参后，线性核的五折平均 AUC 为 0.911160，RBF 核为 0.910040，只差 0.001120，说明当前特征的主要判别信息用线性分界已经能捕捉。要看换核和调参哪个更有效，可以从默认参数比较：直接换成 RBF 核，AUC 下降了 0.012955，而调整 RBF 自身的参数能让它回升 0.012532。gamma 的作用尤其直观：在核函数 K(x,x′)=exp(−gamma·‖x−x′‖²) 中，gamma 越大，相似度随距离衰减得越快，每个训练点影响的范围也越小。当 C=1、gamma=10 时，训练 AUC 达到 1.000000，验证 AUC 却降到 0.711969，正是过拟合的表现。若只用初筛时可得的信息，删去 ca 和 thal 并重新选参后，线性核与 RBF 核的 AUC 分别为 0.865654 和 0.864848，仍是线性核略高。不过，选择线性核的依据是 AUC；如果更关心默认阈值下能检出多少阳性病例，RBF 核的召回率为 0.798413，略高于线性核的 0.784127。

## 2. 两条任务线的结论是否一致

分类和回归都选出了线性模型，但两项任务的差距很不一样。分类中两种核的 AUC 很接近（线性核 0.911160，RBF 核 0.910040），回归中岭回归的 R² 则明显高于回归树（0.524346 和 0.292150）。从测试折的置换重要性看，线性 SVM 和岭回归各自排在前五位的特征里，有四项相同，分别是 cp、exang、ca 和 thal。删去其中的 ca 和 thal 后，岭回归的 R² 降至 0.390989，回归树反而升到 0.346120，差距缩小了，两者的次序依然没变。从删列前后的变化看，这两项检查有助于岭回归估计严重程度，但也可能让树在有限的样本上分得过细。把两条线的结果放在一起看，当前数据中的主要信号用较简单的全局关系就能捕捉，进一步拟合局部差异在本次五折验证中没有提高主指标。

## 3. 回归模型能否用作分类器

岭回归虽然只学过严重程度 num，但阳性本来就定义为 num>0，因此预测的严重程度也可以用来给病例排序。直接用预测值计算五折平均 AUC，岭回归得到 0.909931，与线性 SVM 的 0.911160 很接近。不过，岭回归估计的是给定特征下的平均严重程度：一组患者中少数人病情较重，另一组中较多人病情较轻，两组的平均等级可能相同，阳性比例却不同。把分数转成阳性或阴性判断时，阈值的影响就显出来了。以预测值大于 0.3 为阳性时，岭回归的准确率和 F1 分别为 0.722787 和 0.760533，都低于线性 SVM 默认决策的 0.844754 和 0.821905。把阈值依次提高到 0.5、0.7 和 1.0，前两次两项指标仍低于 SVM，到 1.0 时才分别以 0.851257 和 0.828258 超过它。可见，同一组岭回归分数就能随阈值变化给出相反的优劣判断，实际应用时应在训练数据中选定阈值，再独立评价。

| 岭回归 | 0.300000 | 0.909931 | 0.722787 | 0.760533 |

| 岭回归 | 0.700000 | 0.909931 | 0.821530 | 0.818327 |
| 岭回归 | 1.000000 | 0.909931 | 0.851257 | 0.828258 |
| 回归树（预剪枝） | 0.300000 | 0.825522 | 0.716175 | 0.736028 |
| 回归树（预剪枝） | 0.500000 | 0.825522 | 0.795246 | 0.775119 |
| 回归树（预剪枝） | 0.700000 | 0.825522 | 0.791913 | 0.769990 |

## 补充分析：逐样本配对

上述四个阈值沿用作业第4.6（3）题的示例，用于敏感性分析，没有通过当前测试结果优化阈值。为检查模型是否在同一批患者上判断正确，将岭回归与两种SVM扫描最优配置的折外预测按原始行号配对；每位患者的预测均来自未用该患者训练的模型。

正确样本损失率＝“SVM正确、岭回归错误”的人数／SVM正确人数；错误样本纠正率＝“SVM错误、岭回归正确”的人数／SVM错误人数。前者描述替换模型时损失了多少原本正确的判断，后者描述纠正了多少原有错误；两者分母不同，不能直接相减作为净收益。另列判定不一致率＝两者预测类别不同的人数／303。这些是以SVM为参照的描述性指标，并不把SVM当作真实标签。

线性SVM共判对256例、判错47例；阈值1.0时，岭回归损失其中4例正确判断（1.56%），同时纠正6例错误（12.77%），两者仍共同判错41例。新增的4例错误包括1例漏诊和3例误报；阈值0.3时损失的61例则全部为误报。因此，即使总体accuracy、F1或AUC接近，也不能保证同一个患者得到相同判断，更不能仅凭总分宣称两个模型可以互换。

accuracy只统计正确总数，F1汇总混淆矩阵，均不保留患者身份；一个模型纠正部分病例、同时判错另一些病例，可以得到相近总分。岭回归拟合严重程度num的条件均值，SVM使用二分类间隔目标，两者对重症、轻症及边界病例的权衡不同；改变阈值只能改变岭回归分数上的切分位置，不能任意重排患者，因而不保证复现SVM的逐样本决策。这些机制解释了为何总体表现接近与个体判断不一致可以同时发生，但尚未对每例不一致的原因作因果验证。

本表汇总303例折外预测的人数和比例，区别于上一表先逐折计算再平均的指标；它仍使用课程扫描选出的配置，属于探索性配对分析，不是新增的独立验证或显著性检验。逐例行号、真实等级、预测值与错误归属见[不一致样本清单](figures/paired_disagreements.csv)，row为原CSV零基数据行号、fold为零基折号；完整配对统计见figures/paired_comparison.json。
