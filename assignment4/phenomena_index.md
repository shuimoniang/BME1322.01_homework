# 本数据集反直觉现象与预期不符结果：按作业条款索引

本索引将同一套19条实测记录按4.2、4.3、4.5、4.6归类，与按重要性排列的实验日志互补。一条发现可回应多个条款，交叉出现只是索引，不增加发现数量。

本数据上的模型表现具有数据与候选范围限制；指标定义、错误口径对照、输出约束及选参协议带来的现象，不能全部归因于数据集固有性质。所有条目均附实测数字，完整原因假设、已做验证、验证边界和未做的进一步检验见对应记录。

排名1–5见[主要实验日志](experiment_log.md)及报告第十节；排名6–19见[补充实验发现](additional_findings.md)。原始编号、排名、条款、分类和全部数值见figures/unexpected_findings.json。

## 评估口径与模型边界的补充现象

第16项（独立选参不一定降分）、第18项（预测可越出等级范围）、第19项（验证R²更高而MSE更大）主要涉及方法或指标性质；应与数据集模型表现一并记录，但不称为本数据集独有规律。

这里的第16、18、19项是重要性排名；全部条目都保留原始编号，便于与数值记录核对。
